    Transmis au prompt

    Couleurs de la carte d'après l'illustration : onglet Style, « Couleurs d'après une image ». Dans l'autre sens, la palette « Thème de l'affiche » de l'étape Prompt transmet à l'IA les couleurs de la carte.

    L'illustration est créée par l'IA de votre choix (ChatGPT, Gemini…) : l'application rédige la demande, vous l'y collez, puis vous importez l'image obtenue à l'étape 2.

    Pistes à proposer à l'IA facultatif

    Monuments, cours d'eau, sommets et paysages autour du lieu, lus dans la carte (avec le moteur Fichier : dans les données importées). Touchez une piste pour l'ajouter.

    Option désactivée par défaut. Activée, elle envoie à Wikipédia (fr.wikipedia.org) les seules coordonnées du lieu, avec votre adresse IP ; les lieux les plus connus alentour sont proposés comme pistes.
